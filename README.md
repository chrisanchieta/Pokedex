# 📕 Pokédex

Projeto de uma Pokédex desenvolvida com **HTML, CSS e JavaScript puro**, consumindo a **PokeAPI** para exibir informações detalhadas dos Pokémon.

---

## 🚀 Funcionalidades

- Listagem de Pokémon com paginação
- Exibição de tipos
- Informações básicas (altura, peso e experiência base)
- Habilidades (incluindo habilidade oculta ⭐)
- Moves do Pokémon
- Layout responsivo
- Estilização baseada no tipo do Pokémon

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- [PokeAPI](https://pokeapi.co/)

---

## 📱 Layout Responsivo

O projeto foi pensado para funcionar bem em **dispositivos móveis e desktop**, utilizando boas práticas de CSS e organização visual.
